# 야핑 전략 개요

공유해주신 전략을 기반으로 자동화 파이프라인과 연동할 수 있도록 정리했습니다. 각 전략은 `data/yapping_strategies.yaml`에도 반영되어 있으며, 상호작용 워커가 점수 보너스를 주는 데 활용됩니다.

## 0. 초기선점 (기본 전략)
- 등장 직후/온보딩 단계에서 빠르게 포스팅하여 기본 점수를 확보합니다.
- 현재 대표 계정: `@openmind_agi`, `@GoKiteAI`
- 자동화에서는 "초기선점" 계정을 탐지하면 소폭 가중치를 부여합니다.

## 1. 대감집 노비 전략
- `@MMTFinance`, `@SentientAGI` 같은 대형 계정과 경쟁해 높은 보상을 노립니다.
- 경쟁이 치열하지만 원상 가능성이 높아 기대값이 큽니다.
- 워커는 해당 계정에 대해 높은 보너스를 부여하도록 설정되어 있습니다.

## 2. 빈집털이 전략
- 경쟁이 거의 없는 프로젝트를 집중 공략합니다 (`@Everlyn_ai`, `@billions_ntwk`, `@EdgenTech`).
- 랭킹 상승이 쉽지만 보상폭은 작을 수 있으므로 선별이 중요합니다.

## 3. 카이토 대체재 전략
- Vooi, Limitless, Tria 등 Kaito 외 대체재를 공략합니다.
- 리콜 영향은 있지만 보상 풀이 작을 수 있고 최근 경쟁이 심화되었습니다.

## 4. 키워드 클러스터 전략
- `@bongbongcrypto`님 사례처럼 특정 키워드/생태계를 묶어 연쇄적으로 언급합니다.
- Base, Sui 등 생태계 단위로 포스팅할 때 효과적입니다.

## 5. 보상 없어도 글쓰기 전략
- 보상 공지가 없어도 향후 분배, 리콜 가능성을 보고 글을 남깁니다 (`@megaeth_labs`, `@opensea`, `@AbstractChain`, `@Polymarket`).
- 순수 크립토 인사이트 글과 유사하며, 깜짝 보상을 노릴 수 있습니다.

## 6. 계정 파워 우선 전략
- `@namnin_kr`님처럼 특정 프로젝트보다 계정 자체의 영향력 성장에 집중합니다.
- 단기 효율은 떨어질 수 있으나 장기적으로 여러 랭킹을 쉽게 차지할 수 있습니다.

각 전략의 계정 목록과 가중치는 `data/yapping_strategies.yaml`로 관리되며 필요에 따라 직접 수정할 수 있습니다. 추가 전략이나 계정이 있다면 YAML 파일에 추가한 뒤 `StrategyLoader`를 재시작하면 적용됩니다.
